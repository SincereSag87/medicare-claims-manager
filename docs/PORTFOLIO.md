## Demo Narrative

Medicare Claims Manager is a healthcare revenue cycle operations app that shows claim intake, patient/provider management, controlled workflow transitions, reporting, auditability, administration, and deployment readiness.

## Talking Points

- Built with ASP.NET Core MVC and Razor views.
- Uses ASP.NET Core Identity with role-based authorization.
- Uses SQL Server/Azure SQL through EF Core migrations.
- Includes a controlled claim status workflow with audit history.
- Includes automated tests for workflow and CRUD behavior.
- Includes GitHub Actions CI and Azure App Service deployment workflow.
